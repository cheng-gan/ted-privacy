# Ted — Privacy Policy

Ted is a personal assistant used only by its developer, Cheng Gan, and members of his household. It is not offered to the public.

## Data accessed

When a user signs in with Google, Ted may access:

- **Gmail** (read, label, draft and send messages) — to summarize, organize and reply to email at the user's request.
- **Google Calendar events** (read, create, edit) — to check schedules and manage events at the user's request.
- **Google Drive** (read and write files) — to find, read and save documents at the user's request.

Ted accesses this data only for the signed-in user and only to carry out actions that user asks for.

## Storage and sharing

OAuth tokens and any retrieved data are stored on the developer's private server. Data is not sold, shared with third parties, or used for advertising. Ted's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Retention and deletion

You can revoke Ted's access at any time at <https://myaccount.google.com/permissions>. Stored tokens and data are deleted on request.
